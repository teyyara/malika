# Loop 006 — Grand secret

The Secret Arcade now tracks the five games completed during the current visit. Return to the arcade after each win; each finished game displays a checkmark and the mastery bar advances toward 5 / 5.

## How to unlock it

1. Catch seven stars.
2. Find all three pairs in Mimi's Memory Match.
3. Repeat the rhythm: 🐾 pawprints, 🌙 moon, 💜 purple heart, ✨ sparkle.
4. Catch five fireflies.
5. Reveal all five wishes in the wish jar by shaking it five times.

Once every game is completed, a reward card appears in the arcade. Select **Open the grand secret** to reveal **Keeper of Little Wonders** with a golden-lavender animation and final note from Zack.

Progress and completion marks last only for the current page visit. Replaying a game is allowed, and a refresh resets the hunt. The final reward cannot be unlocked by completing fewer than five games.

Automated coverage lives in `e2e/easter-eggs.spec.js` and verifies all five wins followed by the grand reveal.
